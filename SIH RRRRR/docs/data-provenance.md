# Data Provenance Taxonomy

See section 3.1 of the architecture document for the full provenance taxonomy.

| Label | Meaning |
|---|---|
| `REAL_VERIFIED` | From an official, citable source |
| `PUBLIC_PROXY` | Real public data used as a stand-in |
| `SIMULATED` | Statistically generated, not observed |
| `ASSUMPTION` | A number chosen for demo purposes, explicitly flagged |
| `MODEL_OUTPUT` | Derived by our own models |
